# 掌握多属性筛选，进行高效数据管理

使用查找架构时，通常需要根据多个属性筛选对象列表。 此视频介绍如何使用嵌套 filter() 函数对查找架构执行多属性筛选。 当您需要根据多个条件缩小对象列表时（例如按 ID 和颜色筛选购物车中的产品），此功能特别有用。
