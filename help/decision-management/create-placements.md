# 创建投放位置

了解如何为决策管理创建[放置环境](https://experienceleague.adobe.com/docs/journey-optimizer/using/offer-decisioniong/create-components/creating-placements.html?lang=zh-Hans)。 放置环境是产品建议的构建基块组件之一。 放置环境是内容类型和渠道的组合，例如电子邮件中的图像或网站上的 HTML 代码。
