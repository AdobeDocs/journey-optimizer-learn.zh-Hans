# 创建决策规则

了解如何为决策管理创建[决策规则](https://experienceleague.adobe.com/docs/journey-optimizer/using/offer-decisioniong/create-components/creating-decision-rules.html?lang=zh-Hans)。 规则或“决策规则”是个性化产品建议的必需构建基块组件之一。 规则是使用 Experience Platform 的实时客户轮廓中的事件和属性构建的，并基于产品建议的资格限制。 例如，可以使用规则将雪铲产品建议限制为仅提供给居住在下雪地区的客户。

>[!VIDEO](https://video.tv.adobe.com/v/341363?captions=chi_hans&quality=12&learn=on){transcript=true}

要详细了解如何使用 API 创建决策规则，请参阅[产品指南](https://experienceleague.adobe.com/docs/journey-optimizer/using/offer-decisioniong/api-reference/offers-api/decision-rules/create.html?lang=zh-Hans)
