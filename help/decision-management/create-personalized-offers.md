# 创建个性化优惠

了解如何为决策管理创建[个性化产品建议](https://experienceleague.adobe.com/docs/journey-optimizer/using/offer-decisioniong/managing-offers-in-the-offer-library/creating-personalized-offers.html?lang=zh-Hans)。 个性化产品建议具有与其相关联的资格规则，可帮助您仅向相关客户显示这些产品建议。 例如，您可以将雪铲产品建议限制在下雪地区，并且仅在冬季提供。

>[!VIDEO](https://video.tv.adobe.com/v/341341?captions=chi_hans&quality=12&learn=on){transcript=true}

要了解有关如何使用 API 创建个性化产品建议活动的更多信息，请参阅[产品指南](https://experienceleague.adobe.com/docs/journey-optimizer/using/offer-decisioniong/api-reference/offers-api/personalized-offers/create.html?lang=zh-Hans)
